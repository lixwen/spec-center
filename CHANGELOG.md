# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-30

### Added

- Change lifecycle management (draft, in_review, approved, archived)
- Spec sync from repositories via REST API
- Baseline-aware review with locked snapshots
- Product Spec browser with capability evolution history
- AI review briefs and cross-spec analysis
- RAG-based knowledge Q&A with agent tool use
- Multi-project support with RBAC
- User management with JWT and API token authentication
- Embedding worker for vector indexing
- Docker Compose deployment
- i18n support (English and Chinese)
- MCP server endpoint
